# Code of Conduct

## Our pledge

Everyone taking part in this project, maintainers included, should be able to do so without harassment.
Issues, pull requests and reviews stay respectful and welcoming.

## Expected behaviour

- Assume good faith, and give specific, technical feedback on the work rather than the person.
- Respect that contributors have different experience levels and different amounts of time.
- Keep private vulnerability reports and conduct reports confidential.

## Unacceptable behaviour

- Harassment, insults, threats or discriminatory language.
- Publishing someone else's private information, or sharing code or findings from a repository they did not
  agree to make public.
- Sustained disruption of issues, reviews or pull requests.

## Reporting

Report a conduct concern privately through
[GitHub private vulnerability reporting](https://github.com/developingchet/vuln-hunt/security/advisories/new)
(the **Security** tab, then **Report a vulnerability**) and say in the report that it concerns conduct, not a
vulnerability. GitHub keeps the report confidential. Do not open a public issue about it. The advisory form
serves only as a private inbox here; the repository owner reviews such reports as conduct concerns.

Maintainers review reports privately. A maintainer named in a report does not handle that report; the
repository owner does. There is no separate conduct email address.

## Enforcement

Maintainers may edit or remove a comment, close an issue, ask for a change, or temporarily or permanently
block a contributor. The response is proportional to the behaviour. A contributor can ask for
reconsideration through the same private channel.

## Scope

This applies to issues, pull requests, reviews, comments and private reports on this repository, and to
project spaces where contributors represent the project.
